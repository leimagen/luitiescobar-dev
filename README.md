# dev.luitiescobar.com

Portfolio of Luiti Escobar as an AI developer: case studies of the agents, web apps and games built with
Claude Code since May 2026. English and Spanish. Dark companion to the design portfolio at
[luitiescobar.com](https://luitiescobar.com).

Astro 7 (static) served by Cloudflare Workers static assets.

```
npm install
npm run dev          # local dev server
npm run build        # build to dist/
npx wrangler deploy  # publish dist/ to dev.luitiescobar.com
```
